## Задание для самостоятельной работы

### Ролевой промт

```text
Ты опытный Python-разработчик и преподаватель по веб-разработке.

Мне нужно выполнить лабораторную работу: веб-приложение для генерации изображений по запросу через Hugging Face модель black-forest-labs/FLUX.1-schnell.

Требования:
1. Использовать Flask, Pillow, huggingface_hub, python-dotenv.
2. Реализовать маршрут GET /login, который возвращает JSON:
   {"author": "МОЙ_ЛОГИН_В_MOODLE"}
3. Реализовать маршрут /makeimage:
   - GET /makeimage возвращает HTML-страницу с формой.
   - Форма должна содержать поля:
     width — ширина изображения в пикселях,
     height — высота изображения в пикселях,
     text — текстовый промпт для модели.
   - Форма отправляется методом POST с enctype="application/x-www-form-urlencoded".
4. POST /makeimage:
   - принимает width, height, text;
   - проверяет, что width и height — положительные целые числа;
   - если данные некорректны, возвращает ту же HTML-форму с красным сообщением:
     "Invalid image size";
   - если width или height не кратны 32, возвращает форму с сообщением:
     "Width and height must be multiples of 32";
   - дополнительно ограничить размер от 256 до 1024 пикселей;
   - генерирует изображение через Hugging Face InferenceClient;
   - возвращает изображение в формате JPEG с Content-Type: image/jpeg.
5. API-ключ Hugging Face должен храниться в .env, а не в коде.
6. Нужно обработать ошибки Hugging Face и выводить на форме:
   "Model generation failed: ..."
7. Создать структуру проекта, requirements.txt и .gitignore.
8. Код должен быть понятным, с комментариями.

Сначала предложи структуру проекта и кратко объясни, какие файлы нужны.
Не пиши пока полный код, только структуру и план реализации.
```

### Далее я написал Zero-shot промт

```text
Теперь напиши полный рабочий проект на Flask для этой лабораторной работы.

Сделай следующие файлы:

1. app.py
2. templates/makeimage.html
3. requirements.txt
4. .gitignore
5. .env.example

Требования к app.py:
- загрузить HF_TOKEN из .env через python-dotenv;
- создать InferenceClient;
- реализовать GET /login;
- реализовать GET /makeimage;
- реализовать POST /makeimage;
- валидировать width и height:
  1) должны быть положительными целыми числами;
  2) должны быть кратны 32;
  3) должны быть в диапазоне от 256 до 1024;
- если ошибка валидации, вернуть HTML-форму с переменной message;
- при успешной генерации вызвать модель black-forest-labs/FLUX.1-schnell;
- если модель поддерживает параметры width и height, передать их;
- если изображение пришло другого размера, изменить размер через Pillow;
- конвертировать изображение в RGB;
- сохранить в BytesIO как JPEG quality=90;
- вернуть Response с mimetype="image/jpeg";
- обработать ошибки генерации через try/except.

Требования к HTML:
- простая форма;
- поля width, height, text;
- значения по умолчанию: width=512, height=512, text="cyberpunk cat with neon glasses";
- если message не пустой, вывести его красным цветом над формой.

В requirements.txt укажи:
Flask
Pillow
huggingface-hub
python-dotenv

В .gitignore добавь:
.env
__pycache__/
venv/

В .env.example добавь пример:
HF_TOKEN=your_huggingface_token_here

Выведи полный код каждого файла отдельно.
```
